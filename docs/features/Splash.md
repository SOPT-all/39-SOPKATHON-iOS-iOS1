# Splash

- 담당: Eda3399
- 상태: 진행 중

## 흐름

- 앱 시작 시 온라인 운동회 타이틀과 트랙 비주얼을 표시함.
- 게임 시작 요청 → 상대 팀 매칭 대기 → 매칭 완료 후 게임방 이동(연결 예정).

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `Presentation/Splash/View/SplashView.swift` | 화면 레이아웃과 트랙 배경을 그림 |
| `Presentation/Splash/View/GameWaitingView.swift` | 매칭 대기 화면 레이아웃 |

## 주요 결정

- 375×812 기준으로 배경은 화면을 채우고 타이틀·러너·그림자는 화면 안에 맞춤.
- 시작 화면과 매칭 대기 화면은 진입 시점이 달라 같은 폴더에 개별 View로 둠.
- 대기 화면은 375×812 기준 레이아웃을 동일 비율로 조정하고, 손글씨 SVG에 `accessibilityLabel`을 제공함.

## 주의·남은 일

- 앱 루트에 진입 경로, 노출 시간, 다음 화면 전환 연결 필요.
- 매칭 상태·API와 게임방 이동은 상위 흐름에서 연결 예정. 취소·실패 UI는 미정.
