# 랭킹

- 담당: Eda3399
- 상태: 완료

## 흐름

홈의 랭킹 진입 → 학교/학급 랭킹 선택 → 상위 3위와 전체 순위 확인 → 상단 뒤로가기로 홈 복귀.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `Presentation/Ranking/View/RankingView.swift` | 랭킹 선택, 포디움, 순위 목록 UI |

## 상태와 데이터

- 선택 범위만 로컬 상태로 관리하며 순위와 로고는 Figma 예시 데이터임. 서버 API와 ViewModel은 아직 없음.

## 주요 결정

- 전용 요소는 private 타입으로 두고, 행 간격과 하단 그라데이션을 위해 목록은 `LazyVStack`을 사용함.

## 다른 화면에서 쓸 수 있는 것

- 기존 공통 `TopNavi`를 사용함.

## 주의·남은 일

- 학급 데이터와 하락·유지 디자인은 미정이며, 홈 진입 연결은 홈 담당 화면과 함께 반영해야 함.
