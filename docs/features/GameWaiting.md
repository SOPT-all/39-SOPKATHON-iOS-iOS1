# 게임 대기

- 담당: Eda3399
- 상태: 진행 중

## 흐름

게임 시작 요청 → 상대 팀 매칭을 기다리는 동안 화면 표시 → 매칭 완료 후 게임방 이동(연결 예정).

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `Presentation/GameWaiting/View/GameWaitingView.swift` | 매칭 대기 화면 레이아웃 |

## 상태와 데이터

- 화면 상태와 API 데이터 없음. 매칭 상태는 화면을 소유하는 상위 흐름에서 관리 예정.

## 주요 결정

- 앱 시작용 `SplashView`와 역할이 달라 `GameWaitingView`로 분리함.
- Figma 원본 러너와 문구 그룹 SVG를 사용하고, 375×812 기준 레이아웃을 화면 크기에 맞춰 동일 비율로 조정함.
- 손글씨 문구는 `Text` 대신 SVG 이미지로 표시하고 `accessibilityLabel`을 제공함.

## 다른 화면에서 쓸 수 있는 것

- 없음.

## 주의·남은 일

- 매칭 API, 게임방 이동 시점, 취소·실패 UI가 확정되면 상위 화면에서 연결 필요.
