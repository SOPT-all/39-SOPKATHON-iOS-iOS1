# 서비스 기획

초·중·고등학생이 문답 형식의 영상 릴레이를 포함한 여러 게임을 통해 서로를 알아가고,
반 사이의 교류를 이어가는 iOS 앱.

> 사용자에게 공유받은 초기 기획을 정리한 문서입니다.
> 아래 내용은 기획 방향이며, 기능 구현 완료나 API 명세 확정을 의미하지 않습니다.

## 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | 초·중·고등학생 |
| 해커톤 주제 | 화합 |
| 해결하려는 문제 | 사회성 결여와 끊겨 있는 연결성 |
| 프로덕트 형태 | iOS 앱 |
| 핵심 콘텐츠 | 문답 형식의 반별 영상 릴레이와 참여 방식이 다른 게임 |
| 참여 정원 | 반 전체 등록 정원과 반 안의 게임별 참여 정원을 각각 적용 |
| 목적 | 게임 참여와 교류를 통해 반 사이의 연결을 지속 |

## 문제와 기획 의도

사회성 결여와 끊겨 있는 연결성을 해결하고자 합니다.
문답 형식의 주제를 매개로 영상을 공유하는 릴레이에 더해,
참여 방식이 다른 게임도 제공하여 반 사이의 연결과 교류를 이어가는 것을 목표로 합니다.

## 게임 구성과 참여 정원

- 기존 문답 형식의 영상 릴레이 외에 참여 방식이 다른 게임도 제공합니다.
- 추가 게임의 종류, 구체적인 내용과 진행 규칙은 미정입니다.
- 반 전체 정원은 한 반에 등록할 수 있는 최대 인원입니다.
- 게임별 정원은 해당 반 안에서 각 게임에 참여할 수 있는 최대 인원입니다.
- 두 정원은 서로 구분하며, 수치와 정원 초과 시 처리 방식은 미정입니다.

## 온보딩과 사용자 등록

온보딩에서 다음 정보를 입력하고, 해당 식별 정보를 서버에 등록하는 방식입니다.

| 입력 정보 | 의미 |
| --- | --- |
| 학교 | 소속 학교 |
| 학년 | 소속 학년 |
| 반 | 소속 반 |
| 번호 | 반 내 학생 번호 |
| 이름 | 학생 이름 |

사용자 식별 ID의 생성 방식, 인증 방식, 재접속 시 로그인 처리는 아직 정해지지 않았습니다.

## 핵심 서비스 흐름

1. **온보딩:** 학교·학년·반·번호·이름을 입력하고 서버에 등록합니다.
2. **게임 참여:** 반 전체 정원과 게임별 참여 정원을 구분해 적용합니다.
   추가 게임의 구체적인 참여·진행 흐름은 게임 내용 확정 후 정합니다.

### 기존 영상 릴레이 흐름

1. **주제 확인:** 문답 형식으로 제공되는 주제를 확인합니다.
2. **반별 영상 릴레이 및 공유:** 주제에 따른 문답을 영상 릴레이로 반끼리 공유합니다.
3. **반응 수합:** 앱 안에서 일정 기간 여러 반응을 수합합니다.
4. **순위 산정:** 수합한 반응을 바탕으로 반별 순위를 매깁니다.

반응 수합과 순위 산정은 기존 영상 릴레이 기획입니다.
다른 게임에도 같은 방식을 적용할지는 아직 정해지지 않았습니다.

## 미정 사항

아래 항목은 구현 전에 추가로 확정해야 하며, 현재 문서에서 임의로 정하지 않습니다.

- 서비스 이름
- 추가 게임의 종류·내용·참여 방식·진행 규칙
- 반 전체 등록 정원과 게임별 참여 정원의 수치·설정 기준
- 정원 초과·참여 마감·중도 이탈·재참여 처리 정책
- 다른 게임의 결과 집계·순위 산정 방식과 기존 릴레이 방식의 적용 여부
- 학교·학년·반을 구분하는 기준과 교류 가능한 범위
- 사용자 식별 ID 생성, 인증 및 재접속 방식
- 문답 주제의 제공 주체와 제공 주기
- 영상 릴레이의 참여 단위·순서·다음 반으로 이어지는 규칙
- 영상 촬영·등록 방식과 길이 등 제한
- 앱에서 제공할 반응의 종류와 참여·중복 허용 기준
- 반응 수합 기간과 종료 시점
- 순위 산정 기준과 동점 처리 방식
