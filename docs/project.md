# 서비스 기획

초·중·고등학생이 문답 형식의 반별 영상 릴레이를 통해 서로를 알아가고,
반 사이의 교류를 이어가는 iOS 앱.

> 사용자에게 공유받은 초기 기획을 정리한 문서입니다.
> 아래 내용은 기획 방향이며, 기능 구현 완료나 API 명세 확정을 의미하지 않습니다.

## 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | 초·중·고등학생 |
| 해커톤 주제 | 화합 |
| 해결하려는 문제 | 사회성 결여와 끊겨 있는 연결성 |
| 프로덕트 형태 | iOS 앱 |
| 핵심 콘텐츠 | 문답 형식의 반별 영상 릴레이 |
| 목적 | 문답 공유와 반응을 통해 반별 교류를 지속 |

## 문제와 기획 의도

사회성 결여와 끊겨 있는 연결성을 해결하고자 합니다.
문답 형식의 주제를 매개로 반끼리 영상을 공유하고 반응을 주고받으며,
반 사이의 연결과 교류를 이어가는 것을 목표로 합니다.

## 온보딩과 사용자 등록

온보딩에서 다음 정보를 입력하고, 해당 식별 정보를 서버에 등록하는 방식입니다.

| 입력 정보 | 의미 |
| --- | --- |
| 학교 | 소속 학교 |
| 학년 | 소속 학년 |
| 반 | 소속 반 |
| 번호 | 반 내 학생 번호 |
| 이름 | 학생 이름 |

사용자 식별 ID의 생성 방식, 인증 방식, 재접속 시 로그인 처리는 아직 정해지지 않았습니다.

## 핵심 서비스 흐름

1. **온보딩:** 학교·학년·반·번호·이름을 입력하고 서버에 등록합니다.
2. **주제 확인:** 문답 형식으로 제공되는 주제를 확인합니다.
3. **반별 영상 릴레이 및 공유:** 주제에 따른 문답을 영상 릴레이로 반끼리 공유합니다.
4. **반응 수합:** 앱 안에서 일정 기간 여러 반응을 수합합니다.
5. **순위 산정:** 수합한 반응을 바탕으로 반별 순위를 매깁니다.

이 과정을 통해 반별 교류를 이어가는 것이 서비스의 핵심입니다.

## 미정 사항

아래 항목은 구현 전에 추가로 확정해야 하며, 현재 문서에서 임의로 정하지 않습니다.

- 서비스 이름
- 학교·학년·반을 구분하는 기준과 교류 가능한 범위
- 사용자 식별 ID 생성, 인증 및 재접속 방식
- 문답 주제의 제공 주체와 제공 주기
- 영상 릴레이의 참여 단위·순서·다음 반으로 이어지는 규칙
- 영상 촬영·등록 방식과 길이 등 제한
- 앱에서 제공할 반응의 종류와 참여·중복 허용 기준
- 반응 수합 기간과 종료 시점
- 순위 산정 기준과 동점 처리 방식
